## 15-Minute Demo Call

### Pain discovery (3 min)
- “Think about the last deliverable you sent for approval. Where did the feedback arrive?”
- “How do you know the client approved the latest version, not an earlier one?”
- “What tends to take the most time: gathering comments, following up, or confirming sign-off?”

### Live workflow demo (8 min)
- Create or open a client project and show its deliverables.
- Upload a new version directly to the private file store.
- Set the item to “In review” and create a client review link.
- Open the token link as a client, without an agency login.
- Leave feedback and show the status return to “Changes requested.”
- Reopen the latest version and approve it; show the version-specific decision and activity record.

### Pilot close (4 min)
- “Which current client project is a low-risk place to try this?”
- Agree on one deliverable and one reviewer to invite.
- Set a date to check whether feedback and sign-off stayed clearer than the current process.
- Confirm the agency’s preferred sign-in email and who should own the workspace.
